# GOETIA

Goetia is a dark action roguelike where forbidden rituals grant power, but every choice makes the world more dangerous.

Created in Unity as an original game project.

## About

In Goetia, the player uses occult rituals represented by mystical cards to gain new abilities and alter the course of the game.

Each ritual offers power at a cost. As more cards are chosen and accumulated, the game becomes increasingly difficult, creating a world where magic progressively contaminates power.

## Controls

| Action | Control |
|---|---|
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
| Jump | Space |
| Activate Rituals | E / Left Click / Shift |
| Menu / Pause | Q / Esc |
